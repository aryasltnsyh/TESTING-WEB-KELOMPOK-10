# 🧪 1. Desk Checking
Desk checking adalah metode manual dalam white box testing di mana kamu memeriksa kode program baris demi baris tanpa menjalankan programnya.
---
# 🧭 2. Control Flow Testing
Control flow testing adalah teknik pengujian yang berfokus pada struktur kontrol program, seperti if, while, for, dan switch. Kamu memastikan semua jalur logika sudah dieksekusi setidaknya satu kali.
---
🔁 3. Basic Path Testing (Bagian dari Control Flow Testing)
Basic Path Testing adalah metode dalam control flow testing yang mengevaluasi semua jalur dasar (basic paths) dari program untuk memastikan semua bagian kode telah diuji.
---
