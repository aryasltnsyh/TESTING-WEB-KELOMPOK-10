
Pattern Testing, juga dikenal sebagai "Discovery Testing" atau "Exploratory Testing",
Digunakan untuk pendekatan pengujian perangkat lunak yang berfokus pada eksplorasi dan
penemuan bug secara kreatif dan inovatif. Metode pengujian yang fokus pada pola-pola tipikal yang muncul dalam interaksi sistem, baik dari sisi input, output, maupun perilaku sistem.
Teknik ini menekankan pada pemikiran
kritis, intuisi, dan pengalaman tester untuk mengidentifikasi potensi masalah yang
mungkin terlewatkan oleh tes formal.
Tahapan dalam Pengujian Pattern Testing :

1. Menguji Fungsional Dasar
2. Menguji Batasan dan Skenario tidak terduga
3. Menguji Performa dan Stabilitas
4. Menguji Kegunaan dan Pengalaman Pengguna
